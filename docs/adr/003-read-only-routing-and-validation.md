# ADR-003: explicit read-only routing support

Date: 2026-10-16. Classification: LOCAL EXTENSION. Status: implemented.

The V1 context retriever returns bounded source snippets; it does not select
versioned functional-skill metadata or produce validated execution-list handoff
plans. Keep it unchanged. Add `office.py` for those approved capabilities with
Python stdlib only. It must never invoke an agent/provider, install tools,
execute a catalog entry, authorize scope, or emit a runtime PASS.

Library indexes are content-addressed metadata caches over canonical resources;
queries reject stale entries and prefer caller-supplied Task/project/local
indexes before the distributed index. External gaps hand off to existing
research capabilities, retaining permission and provenance requirements.
No automatic network fetcher or competing MCP/runtime state store is added.

The existing contract model has templates and structural tests, rather than a
published executable JSON Schema. V2 checks routing-critical fields, graphs,
owners, checklists, revisions and source anchors. `contracts/` resolves the
canonical definitions. It does not claim exhaustive semantic spec validation
or replace Human Task equivalence and current dependency receipts. Independent
QA reproduced seven invalid-handoff cases; all are now rejected with tests.

Security revalidation also checks resolved private paths and rejects symlink
sources outside the bundle. This is local metadata privacy hardening, not a
claim of a network vulnerability. New helpers are shared canonical scripts;
platform overlays do not duplicate them.

Rollback: stop using the V2 route and select the preserved V1 bundle. No client
project, provider configuration or installed cache has been changed.

## Generated bytecode cleanup

V1 tracked four CPython 3.11 cache files. Retaining immutable hashes at active
`tests/__pycache__/` paths would make preservation checks fail when Python 3.11
legitimately regenerates them. Archive their exact original bytes under
`docs/migration/v1-bytecode/` and keep runtime caches ignored. The preservation
checker resolves these four inventory entries to the archives. No Python source
or test is removed; bytecode is generated by the interpreter, never a canonical
procedure. README/AGENTS originals are likewise archived when adapting root
entrypoints. This is a packaging correction inside the approved migration.
